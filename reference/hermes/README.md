# The first device: a worked example

From a LineageOS 21 port to an Allwinner H723 projector. **Addresses, module names and partition names apply to that device only.**

These notes were copied from that project's repository, so **some links point to folders that aren't here**, like `../firmware/` and `../tooling/`. They hold firmware and per-device data, which this toolkit doesn't include. Files with similar names are here, in `rescue-stick/`, `donor-extract/` and `env-fastboot-trigger/`. Where these notes refer to `docs/02-security-findings.md`, it isn't included either.

The notes record what was believed at the time, including theories later proven wrong. Later entries and `docs/07-CASE-STUDY.md` take priority.

The device tree is for reading only: see `device-tree/MISSING-STOCK-FILES.md`.
